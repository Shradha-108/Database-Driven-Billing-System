Technologies:
Embedded C | STM32F103C8T6 (ARM Cortex-M3) | UART | RFID | LCD | Keypad | Linux | MySQL 


This project implements a real-time, database-driven billing system using the STM32F103 microcontroller. The system identifies users via RFID cards, allows item selection using a 4×4 keypad, displays billing details on an LCD, and transmits transaction data to a Linux-based host system over UART, where it is stored in a database for logging and analysis.

The project is designed to simulate smart billing counters, canteen billing, metro/ticketing systems, or access-based transaction logging systems.
