# Database-Driven-Billing-System
Embedded C | STM32F103 (ARM Cortex-M3) | UART | Linux DB Integration

This project implements a real-time, database-driven embedded billing system using the STM32F103 microcontroller and RFID technology.
The system automatically identifies users via RFID cards, processes billing transactions through a keypad interface, and transmits transaction data to a Linux-based host system via UART. The host system stores and manages all billing data in a centralized database for record keeping and analysis.
The solution is designed for retail counters, canteens, toll booths, access-based billing systems, and prepaid services, ensuring fast, reliable, and low-power operation on resource-constrained embedded hardware
